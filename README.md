## 📖 About

**DSA in Python** is a personal learning repository that contains Python implementations of popular **searching**, **sorting**, and other fundamental algorithms.

The goal of this repository is to build a strong foundation in problem-solving and algorithmic thinking while continuously expanding the collection with new topics and optimized solutions.

Whether you're preparing for coding interviews, improving your programming skills, or learning DSA from scratch, this repository serves as a useful reference.

# 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/jillasrivardhan/DSA-in-Python.git
```

### 2. Navigate to the Project Directory

```bash
cd DSA-in-Python
```

### 3. Run Any Program

Example:

```bash
python bubble_sort.py
```

or

```bash
python linear_search.py
```
